# 12. Glossary

| Term (EN)         | Term (DE)                 | Meaning                                                                                      |
| ----------------- | ------------------------- | -------------------------------------------------------------------------------------------- |
| ECC I / ECC II    | ECC I / ECC II            | The club's first and second league teams.                                                    |
| Fixture           | Spiel / Begegnung         | A scheduled league match of an ECC team, maintained on the website.                          |
| Practice          | Training                  | The weekly team training: Wednesday before a Saturday match, Thursday before a Sunday match. |
| Availability      | Verfügbarkeit             | A member's answer for a match or practice: Going or Not going (with reason).                 |
| Going / Not going | Dabei / Nicht dabei       | The two possible answers.                                                                    |
| Attendance        | Anwesenheit               | Whether a player was at a practice, marked by the captain.                                   |
| Walk-in           | Spontan dabei             | A player who came to practice without having answered Going; added by the captain.           |
| Attendance rule   | Trainingsregel            | At least 2 of the team's last 4 practices attended to be selectable.                         |
| Countdown         | Restbedarf                | What a player still needs within the window, e.g. "attend 2 of the next 3".                  |
| Team squad        | Mannschaftskader          | The players assigned to a team by the admin (about 15, may grow to 17–18).                   |
| Match squad       | Spielkader                | The players a captain selects for one match, from the team squad and helpers.                |
| Playing XI        | Startelf                  | The eleven players who take the field.                                                       |
| 12th man          | 12. Mann                  | The substitute fielder of a match squad; plays the team's next match automatically.          |
| Reserve           | Ersatzspieler             | An extra player in a match squad, e.g. for two games on one day; plays the next match too.   |
| Carry-over        | Übernahme                 | A 12th man or reserve moving into the team's next playing XI without selection.              |
| Approval          | Freigabe                  | The admin's confirmation of a captain's squad.                                               |
| Deadline          | Meldeschluss              | When availability for a match closes: end of Tuesday unless extended.                        |
| Exception         | Ausnahme                  | An admin making an ineligible player selectable for one match.                               |
| ECC I eligible    | Für ECC I spielberechtigt | Admin flag: the player may be selected for ECC I.                                            |
| Spielerpass       | Spielerpass               | The player's registration card, shown to the umpire before a match.                          |
| Captain           | Kapitän                   | Leads one team: marks attendance and selects the squad.                                      |
| Admin             | Vorstand / Admin          | Board member with all rights.                                                                |
| PWA               | PWA (Web-App)             | Installable web app: opens like an app from the Home Screen and receives push notifications. |
| Push subscription | Push-Abo                  | A device's registration to receive notifications.                                            |
| Tick              | Takt                      | The hourly scheduled call that runs whatever is due.                                         |
